# আরও পড়াশোনা ও রেফারেন্স (Further Reading & References)

- [Geohash — Wikipedia](https://en.wikipedia.org/wiki/Geohash) — driver location-কে proximity অনুযায়ী index ও shard করতে ব্যবহৃত geospatial encoding scheme।
- [Quadtree — Wikipedia](https://en.wikipedia.org/wiki/Quadtree) — adaptive, density-aware location partitioning-এর জন্য বিকল্প spatial indexing structure।
- [Saga pattern — Wikipedia](https://en.wikipedia.org/wiki/Long-lived_transaction#Sagas) — trip lifecycle-এর জন্য ব্যবহৃত long-lived transaction / saga model সম্পর্কে পটভূমি।
- [Two-phase commit protocol — Wikipedia](https://en.wikipedia.org/wiki/Two-phase_commit_protocol) — একটি বিকল্প হিসেবে আলোচিত distributed transaction protocol (এবং কেন এটি এখানে ভালো মানানসই নয়)।
- [Uber Engineering Blog](https://eng.uber.com/) — Uber-এর অফিসিয়াল engineering blog, যেখানে বড় স্কেলে geospatial indexing, dispatch, এবং platform architecture নিয়ে বাস্তব-জগতের পোস্ট রয়েছে।
- [Redis Geospatial commands](https://redis.io/docs/latest/develop/data-types/geospatial/) — geo-sharded location store বাস্তবায়নে ব্যবহৃত একটি সাধারণ building block-এর অফিসিয়াল ডকুমেন্টেশন।
