# Module 1: Foundations

পুরো System Design কোর্সের ভিত্তি তৈরি করে এই module। Load balancer, database, বা distributed algorithm-এ ঢোকার আগে আপনার একটা common vocabulary এবং mental model দরকার: system design আসলে কী, requirements কীভাবে architecture-কে shape করে, machine-গুলো internet-এর মাধ্যমে কীভাবে কথা বলে, এবং scalability ও reliability — এই দুই core lever, যার বিপরীতে পরবর্তী প্রতিটি design decision trade-off করবে। এই পাঁচটি video ভালোভাবে আয়ত্ত করলে পরবর্তী প্রতিটি module (networking, database, caching, messaging, distributed systems, architecture patterns, এবং full case study) এগুলোর উপর ভিত্তি করেই clean-ভাবে গড়ে উঠবে।
