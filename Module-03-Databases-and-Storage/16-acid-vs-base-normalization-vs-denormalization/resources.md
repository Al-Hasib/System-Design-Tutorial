# Further Reading & References

## Official Docs

- [PostgreSQL: Transactions](https://www.postgresql.org/docs/current/tutorial-transactions.html) — official documentation on transactions and ACID behavior in PostgreSQL.
- [PostgreSQL: Transaction Isolation](https://www.postgresql.org/docs/current/transaction-iso.html) — details on read committed, repeatable read, and serializable isolation levels.
- [MongoDB: Data Modeling Introduction](https://www.mongodb.com/docs/manual/core/data-modeling-introduction/) — official guidance on embedding (denormalization) vs referencing (normalization) in document schemas.
- [MongoDB: Data Model Design](https://www.mongodb.com/docs/manual/core/data-model-design/) — trade-offs between normalized and denormalized document design.

## Further Reading

- [Wikipedia: ACID](https://en.wikipedia.org/wiki/ACID) — overview of Atomicity, Consistency, Isolation, and Durability.
- [Wikipedia: Eventual consistency](https://en.wikipedia.org/wiki/Eventual_consistency) — background on eventual consistency and the BASE model.
- [Wikipedia: Database normalization](https://en.wikipedia.org/wiki/Database_normalization) — normal forms (1NF, 2NF, 3NF) and the goals of normalization.
