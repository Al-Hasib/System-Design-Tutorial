# Module 3: Databases & Storage

প্রতিটা system design interview এবং প্রতিটা real production system শেষ পর্যন্ত একটা প্রশ্নে গিয়ে দাঁড়ায়: আপনার data কোথায় এবং কীভাবে store করবেন? এই module-এ core decision-গুলো নিয়ে আলোচনা করা হয়েছে — একটা database model বেছে নেওয়া, index দিয়ে read দ্রুত করা, replication-এর মাধ্যমে data safe ও available রাখা, sharding দিয়ে একটা মাত্র machine-এর বাইরে গিয়ে write scale করা, এবং এই সবকিছু নিয়ন্ত্রণ করা theoretical limit (CAP/PACELC) ও consistency trade-off (ACID vs BASE) বোঝা। এই fundamental-গুলো ঠিকভাবে বুঝলে এর উপর যা কিছু build করবেন — caching, messaging, microservices — তার একটা শক্ত foundation থাকবে; ভুল বুঝলে অন্য কোথাও যত clever architecture-ই বানান না কেন, তা আপনাকে বাঁচাতে পারবে না।
