# Further Reading & References

- [Geohash — Wikipedia](https://en.wikipedia.org/wiki/Geohash) — the geospatial encoding scheme used to index and shard driver locations by proximity.
- [Quadtree — Wikipedia](https://en.wikipedia.org/wiki/Quadtree) — the alternative spatial indexing structure for adaptive, density-aware location partitioning.
- [Saga pattern — Wikipedia](https://en.wikipedia.org/wiki/Long-lived_transaction#Sagas) — background on the long-lived transaction / saga model used for the trip lifecycle.
- [Two-phase commit protocol — Wikipedia](https://en.wikipedia.org/wiki/Two-phase_commit_protocol) — the distributed transaction protocol discussed as an alternative (and why it's a poor fit here).
- [Uber Engineering Blog](https://eng.uber.com/) — Uber's official engineering blog, covering real-world posts on geospatial indexing, dispatch, and platform architecture at scale.
- [Redis Geospatial commands](https://redis.io/docs/latest/develop/data-types/geospatial/) — official documentation for a common building block used to implement geo-sharded location stores.
