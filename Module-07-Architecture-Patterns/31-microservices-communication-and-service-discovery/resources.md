# Further Reading & References

## Official Docs

- [Consul by HashiCorp — Documentation](https://developer.hashicorp.com/consul/docs) — official docs for a widely used service discovery and service mesh tool.
- [Netflix Eureka — GitHub Wiki](https://github.com/Netflix/eureka/wiki) — official documentation for Netflix's client-side discovery service registry.
- [Kubernetes Documentation — Service](https://kubernetes.io/docs/concepts/services-networking/service/) — how Kubernetes implements server-side service discovery natively.
- [Istio Documentation](https://istio.io/latest/docs/) — official docs for the popular open-source service mesh.

## Further Reading

- [Martin Fowler / Chris Richardson — microservices.io: Service Discovery Pattern](https://microservices.io/patterns/client-side-discovery.html) — canonical pattern write-up comparing client-side and server-side discovery.
- [Wikipedia — Service mesh](https://en.wikipedia.org/wiki/Service_mesh) — background on the service mesh concept and sidecar proxy model.
