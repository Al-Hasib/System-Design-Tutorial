# আরও পড়াশোনা ও রেফারেন্স

## অফিসিয়াল ডকস / প্রাথমিক উৎস

- এরিক ইভান্স (Eric Evans), *Domain-Driven Design: Tackling Complexity in the Heart of Software* (২০০৩) — যে ভিত্তিমূলক বইটি DDD, ubiquitous language, এবং bounded context ধারণাগুলো প্রবর্তন করেছিল।
- [Domain Language — DDD Reference (by Eric Evans)](https://www.domainlanguage.com/ddd/reference/) — বইটির মূল প্যাটার্নগুলো সংক্ষিপ্ত করে একটি বিনামূল্যের রেফারেন্স।
- [Martin Fowler — Bounded Context](https://martinfowler.com/bliki/BoundedContext.html) — bounded context ধারণা এবং সার্ভিস সীমানার সাথে এর প্রাসঙ্গিকতার একটি সংক্ষিপ্ত ব্যাখ্যা।

## আরও পড়াশোনা

- [Martin Fowler — DomainDrivenDesign](https://martinfowler.com/bliki/DomainDrivenDesign.html) — মার্টিন ফাউলারের bliki থেকে DDD-এর একটি সংক্ষিপ্ত পর্যালোচনা।
- [Wikipedia — Domain-driven design](https://en.wikipedia.org/wiki/Domain-driven_design) — সাধারণ পর্যালোচনা, ইতিহাস, এবং সম্পর্কিত ধারণাসমূহ (ubiquitous language, aggregate, bounded context)।
- [microservices.io — Pattern: Decompose by subdomain](https://microservices.io/patterns/decomposition/decompose-by-subdomain.html) — ক্রিস রিচার্ডসনের প্যাটার্ন ক্যাটালগ এন্ট্রি যা DDD subdomain-কে microservice decomposition-এর সাথে সংযুক্ত করে।
