# আরও পড়াশোনা ও তথ্যসূত্র

## Official Docs

- [Consul by HashiCorp — Documentation](https://developer.hashicorp.com/consul/docs) — ব্যাপকভাবে ব্যবহৃত একটি service discovery এবং service mesh টুলের official docs।
- [Netflix Eureka — GitHub Wiki](https://github.com/Netflix/eureka/wiki) — Netflix-এর client-side discovery service registry-এর official documentation।
- [Kubernetes Documentation — Service](https://kubernetes.io/docs/concepts/services-networking/service/) — Kubernetes কীভাবে natively server-side service discovery implement করে।
- [Istio Documentation](https://istio.io/latest/docs/) — জনপ্রিয় open-source service mesh-এর official docs।
