# Module 1: Foundations

This module lays the groundwork for the entire System Design course. Before diving into load balancers, databases, or distributed algorithms, you need a shared vocabulary and mental model: what system design actually is, how requirements shape architecture, how machines talk to each other over the internet, and the two core levers — scalability and reliability — that every later design decision will trade off against. Master these five videos and every subsequent module (networking, databases, caching, messaging, distributed systems, architecture patterns, and full case studies) will build cleanly on top of them.
