# Further Reading & References

## Official Docs

- [PostgreSQL Documentation](https://www.postgresql.org/docs/) — Official docs for one of the most widely used open-source relational databases.
- [MySQL Documentation](https://dev.mysql.com/doc/) — Official reference and guides for MySQL.
- [MongoDB Manual](https://www.mongodb.com/docs/manual/) — Official documentation for the leading document-oriented NoSQL database.
- [Redis Documentation](https://redis.io/docs/latest/) — Official docs for the popular in-memory key-value store.
- [Apache Cassandra Documentation](https://cassandra.apache.org/doc/latest/) — Official docs for the wide-column, horizontally-scalable NoSQL database.

## Further Reading

- [Wikipedia: NoSQL](https://en.wikipedia.org/wiki/NoSQL) — Overview of NoSQL databases, history, and categories.
- [Wikipedia: Relational Database](https://en.wikipedia.org/wiki/Relational_database) — Background on the relational model and its theoretical foundations.
- [Wikipedia: ACID](https://en.wikipedia.org/wiki/ACID) — Explanation of Atomicity, Consistency, Isolation, and Durability guarantees.
