# Further Reading & References

## Official Docs

- [MongoDB Manual: Sharding](https://www.mongodb.com/docs/manual/sharding/) — MongoDB's native sharding architecture, shard keys, and chunk balancing.
- [Vitess Documentation](https://vitess.io/docs/) — A database clustering system for horizontal scaling of MySQL, including sharding, resharding, and vindexes (shard-key routing).
- [Citus Documentation](https://docs.citusdata.com/en/stable/) — Citus extends PostgreSQL with distributed tables (sharding) and distributed query execution.
- [Apache Cassandra Documentation](https://cassandra.apache.org/doc/latest/) — Cassandra's architecture, including partitioners and how partition keys map data across the ring.

## Further Reading

- [Wikipedia: Shard (database architecture)](<https://en.wikipedia.org/wiki/Shard_(database_architecture)>) — General overview of the sharding concept, history, and terminology.
- [Wikipedia: Partition (database)](<https://en.wikipedia.org/wiki/Partition_(database)>) — Overview of database partitioning, including horizontal and vertical partitioning.
