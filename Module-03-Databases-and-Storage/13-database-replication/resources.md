# Further Reading & References

## Official Docs

- [PostgreSQL: High Availability, Load Balancing, and Replication](https://www.postgresql.org/docs/current/high-availability.html) — Official documentation covering streaming replication, synchronous replication, and failover in PostgreSQL.
- [MySQL: Replication](https://dev.mysql.com/doc/refman/8.4/en/replication.html) — Official MySQL manual chapter on setting up and configuring source/replica replication.
- [MongoDB: Replica Sets](https://www.mongodb.com/docs/manual/replication/) — Official documentation on MongoDB's replica set architecture, elections, and failover.

## Further Reading

- [Wikipedia: Replication (computing)](https://en.wikipedia.org/wiki/Replication_(computing)) — General overview of data replication concepts, including database replication.
- [Wikipedia: Multi-master replication](https://en.wikipedia.org/wiki/Multi-master_replication) — Background on multi-leader/multi-master replication and conflict handling approaches.
- [AWS: What is Database Replication?](https://aws.amazon.com/what-is/database-replication/) — Vendor-neutral introduction to replication concepts, topologies, and use cases.
