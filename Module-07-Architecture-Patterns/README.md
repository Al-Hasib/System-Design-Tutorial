# Module 7: Architecture Patterns

This module zooms out from individual building blocks to the shape of the whole system. You'll learn how to decide between a monolith and microservices, how independently deployed services find and talk to each other reliably at runtime, and how Domain-Driven Design gives you a principled way to draw service boundaries around business capabilities rather than technical layers. Together these videos connect the low-level primitives from earlier modules (load balancers, message queues, databases) into an organizational and architectural strategy for structuring real systems and the teams that own them.
