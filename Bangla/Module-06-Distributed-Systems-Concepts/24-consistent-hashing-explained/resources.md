# Further Reading & References

## Official Docs

- [Apache Cassandra Documentation — Partitioners](https://cassandra.apache.org/doc/stable/cassandra/architecture/dynamo.html) — Cassandra কীভাবে row key-কে token ring-এ ম্যাপ করে এবং virtual node configure করে।
- [Amazon DynamoDB Documentation](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/Introduction.html) — অফিসিয়াল developer guide, partitioning এবং scaling behavior সহ।

## Papers

- Karger, D., Lehman, E., Leighton, T., Panigrahy, R., Levine, M., Lewin, D. (1997). ["Consistent Hashing and Random Trees: Distributed Caching Protocols for Relieving Hot Spots on the World Wide Web"](https://dl.acm.org/doi/10.1145/258533.258660) — মূল consistent hashing paper।
- DeCandia, G. et al. (2007). ["Dynamo: Amazon's Highly Available Key-value Store"](https://www.allthingsdistributed.com/files/amazon-dynamo-sosp2007.pdf) — যে paper distributed database-এর জন্য virtual node সহ consistent hashing-কে জনপ্রিয় করে তোলে।
