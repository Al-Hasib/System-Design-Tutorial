# Further Reading & References

## Official Docs / Primary Sources

- [Martin Fowler — Microservices](https://martinfowler.com/articles/microservices.html) — the widely cited definition and characteristics of microservices architecture.
- [Martin Fowler — MonolithFirst](https://martinfowler.com/bliki/MonolithFirst.html) — the argument for starting with a monolith before splitting into services.
- [Martin Fowler — StranglerFigApplication](https://martinfowler.com/bliki/StranglerFigApplication.html) — the incremental migration pattern referenced in this video.

## Further Reading

- [Wikipedia — Microservices](https://en.wikipedia.org/wiki/Microservices) — general overview and history of the architectural style.
- [Wikipedia — Monolithic application](https://en.wikipedia.org/wiki/Monolithic_application) — background on monolithic architecture.
- [Segment Engineering — Goodbye Microservices](https://segment.com/blog/goodbye-microservices/) — real-world case study on consolidating microservices back into a monolith.
