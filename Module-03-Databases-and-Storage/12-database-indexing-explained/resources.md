# Further Reading & References

## Official Docs

- [PostgreSQL Documentation — Chapter 11: Indexes](https://www.postgresql.org/docs/current/indexes.html) — official guide covering index types (B-tree, hash, GiST, GIN, BRIN), multicolumn indexes, and index-only scans.
- [PostgreSQL Documentation — Index Types](https://www.postgresql.org/docs/current/indexes-types.html) — details on when to use B-tree vs hash vs other PostgreSQL index types.
- [MySQL Reference Manual — InnoDB and MyISAM Index Types](https://dev.mysql.com/doc/refman/8.0/en/index-btree-hash.html) — explains B-tree and hash index characteristics as implemented in MySQL storage engines.
- [MySQL Reference Manual — Optimization and Indexes](https://dev.mysql.com/doc/refman/8.0/en/mysql-indexes.html) — how MySQL uses indexes, including composite/multi-column indexes.

## Further Reading

- [Wikipedia — B-tree](https://en.wikipedia.org/wiki/B-tree) — background on B-tree structure, balancing, and the B+tree variant used by most databases.
- [Wikipedia — Hash table](https://en.wikipedia.org/wiki/Hash_table) — the underlying data structure behind hash indexes, including collision handling.
