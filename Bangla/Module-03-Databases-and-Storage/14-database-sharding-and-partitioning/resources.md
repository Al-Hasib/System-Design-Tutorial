# আরও পড়াশোনা ও রেফারেন্স

## অফিসিয়াল ডকুমেন্টেশন

- [MongoDB Manual: Sharding](https://www.mongodb.com/docs/manual/sharding/) — MongoDB-র native sharding architecture, shard key, এবং chunk balancing।
- [Vitess Documentation](https://vitess.io/docs/) — MySQL-এর horizontal scaling-এর জন্য একটি ডেটাবেস clustering সিস্টেম, যার মধ্যে আছে sharding, resharding, এবং vindexes (shard-key routing)।
- [Citus Documentation](https://docs.citusdata.com/en/stable/) — Citus PostgreSQL-কে distributed table (sharding) এবং distributed query execution দিয়ে বিস্তৃত করে।
- [Apache Cassandra Documentation](https://cassandra.apache.org/doc/latest/) — Cassandra-র architecture, যার মধ্যে আছে partitioner এবং partition key কীভাবে ring জুড়ে ডেটা map করে।

## আরও পড়াশোনা

- [Wikipedia: Shard (database architecture)](<https://en.wikipedia.org/wiki/Shard_(database_architecture)>) — sharding ধারণা, ইতিহাস, এবং পরিভাষার সাধারণ পর্যালোচনা।
- [Wikipedia: Partition (database)](<https://en.wikipedia.org/wiki/Partition_(database)>) — database partitioning-এর পর্যালোচনা, যার মধ্যে আছে horizontal এবং vertical partitioning।
