## Official Docs

- [PostgreSQL Documentation](https://www.postgresql.org/docs/) — সবচেয়ে বহুল ব্যবহৃত open-source relational database গুলোর একটির official docs।
- [MySQL Documentation](https://dev.mysql.com/doc/) — MySQL-এর official reference এবং guide।
- [MongoDB Manual](https://www.mongodb.com/docs/manual/) — সবচেয়ে শীর্ষস্থানীয় document-oriented NoSQL database-এর official documentation।

- [Apache Cassandra Documentation](https://cassandra.apache.org/doc/latest/) — wide-column, horizontally-scalable NoSQL database-এর official docs।
