# Further Reading & References

## Official Docs

- [MDN: How the Web Works](https://developer.mozilla.org/en-US/docs/Learn/Getting_started_with_the_web/How_the_Web_works) — Mozilla's beginner-friendly overview of clients, servers, and the request/response cycle.
- [MDN: An Overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) — Official HTTP protocol reference and concepts.
- [ICANN: Beginner's Guide to DNS](https://www.icann.org/resources/pages/dns-beginners-2015-11-05-en) — Official explanation of the Domain Name System.

## Papers

- [RFC 793 — Transmission Control Protocol](https://www.rfc-editor.org/rfc/rfc793) — The original TCP specification.
- [RFC 1035 — Domain Names: Implementation and Specification](https://www.rfc-editor.org/rfc/rfc1035) — The core DNS specification.
- [RFC 9110 — HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) — Current official HTTP semantics specification.

## Further Reading

- [Wikipedia: Client-Server Model](https://en.wikipedia.org/wiki/Client%E2%80%93server_model) — Overview of the client-server architecture pattern.
- [Wikipedia: Internet Protocol Suite](https://en.wikipedia.org/wiki/Internet_protocol_suite) — Background on the TCP/IP stack.
