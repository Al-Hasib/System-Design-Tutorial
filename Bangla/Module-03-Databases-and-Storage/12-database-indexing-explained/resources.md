# আরও পড়াশোনা ও তথ্যসূত্র (Further Reading & References)

## অফিসিয়াল ডকুমেন্টেশন

- [PostgreSQL Documentation — Chapter 11: Indexes](https://www.postgresql.org/docs/current/indexes.html) — index type (B-tree, hash, GiST, GIN, BRIN), multicolumn index, এবং index-only scan নিয়ে অফিসিয়াল গাইড।
- [PostgreSQL Documentation — Index Types](https://www.postgresql.org/docs/current/indexes-types.html) — কখন B-tree বনাম hash বনাম অন্যান্য PostgreSQL index type ব্যবহার করবেন তার বিস্তারিত।
- [MySQL Reference Manual — InnoDB and MyISAM Index Types](https://dev.mysql.com/doc/refman/8.0/en/index-btree-hash.html) — MySQL storage engine-এ বাস্তবায়িত B-tree এবং hash index-এর বৈশিষ্ট্য ব্যাখ্যা করে।
- [MySQL Reference Manual — Optimization and Indexes](https://dev.mysql.com/doc/refman/8.0/en/mysql-indexes.html) — MySQL কীভাবে index ব্যবহার করে, composite/multi-column index সহ।

## আরও পড়াশোনা

- [Wikipedia — B-tree](https://en.wikipedia.org/wiki/B-tree) — B-tree structure, balancing, এবং বেশিরভাগ database-এ ব্যবহৃত B+tree variant-এর পটভূমি।
- [Wikipedia — Hash table](https://en.wikipedia.org/wiki/Hash_table) — hash index-এর পেছনে থাকা underlying data structure, collision handling সহ।
