# Further Reading & References

## Official Docs / Primary Sources

- Eric Evans, *Domain-Driven Design: Tackling Complexity in the Heart of Software* (2003) — the foundational book that introduced DDD, ubiquitous language, and bounded contexts.
- [Domain Language — DDD Reference (by Eric Evans)](https://www.domainlanguage.com/ddd/reference/) — a free condensed reference summarizing the book's core patterns.
- [Martin Fowler — Bounded Context](https://martinfowler.com/bliki/BoundedContext.html) — concise explanation of the bounded context concept and its relevance to service boundaries.

## Further Reading

- [Martin Fowler — DomainDrivenDesign](https://martinfowler.com/bliki/DomainDrivenDesign.html) — short overview of DDD from Martin Fowler's bliki.
- [Wikipedia — Domain-driven design](https://en.wikipedia.org/wiki/Domain-driven_design) — general overview, history, and related concepts (ubiquitous language, aggregates, bounded context).
- [microservices.io — Pattern: Decompose by subdomain](https://microservices.io/patterns/decomposition/decompose-by-subdomain.html) — Chris Richardson's pattern catalog entry connecting DDD subdomains to microservice decomposition.
